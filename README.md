# Exercícios - Linguagem C

Repositório destinado à resolução de exercício de algoritmos, desenvolvida em C utilizando o Dev-C++.

## 🚀 Funcionalidades
O código contempla as seguintes funções:
- Conversão de tempo (Horas:Minutos:Segundos).
- Verificação de paridade (`isPar` e `isImpar`).
- Cálculo de média entre dois números.
- Identificação de maior e menor valor.

## 🛠️ Tecnologias Utilizadas
- Linguagem C
- IDE: Dev-C++
